# AI Monitor - Swift Playgrounds App

> 🚀 开箱即用的 macOS 系统监控工具
> 无需编译，无需 Xcode，双击运行！

## ✨ 特性

- ✅ **零门槛使用** - 双击即可运行，无需开发环境
- ✅ **实时监控** - CPU、内存、网络流量实时显示
- ✅ **AI 应用检测** - 自动检测 Ollama、LM Studio、ChatGPT 等
- ✅ **美观界面** - 现代 SwiftUI 设计
- ✅ **轻量高效** - 系统资源占用极低

## 🚀 快速开始

### 方式一：在 Mac 上运行

1. **双击打开**
   ```
   AIMonitor-Playgrounds.swiftpm
   ```

2. **自动启动**
   - 如果你的 Mac 已安装 Swift Playgrounds，会自动打开
   - 如果没有，系统会提示安装

3. **开始使用**
   - 点击"运行"按钮即可看到监控界面

### 方式二：使用 Swift Playgrounds App

1. **安装 Swift Playgrounds**
   - 从 Mac App Store 免费下载
   - [下载链接](https://apps.apple.com/app/swift-playgrounds/id1496833156)

2. **打开项目**
   ```
   在 Swift Playgrounds 中打开 AIMonitor-Playgrounds.swiftpm
   ```

3. **运行应用**
   - 点击右上角的"运行"按钮
   - 或使用快捷键 `⌘R`

### 方式三：使用终端（开发者）

```bash
cd AIMonitor-Playgrounds.swiftpm
swift run
```

### 性能优化

- 数据每秒自动更新
- AI 应用检测每 5 秒刷新一次
- 关闭窗口时自动停止监控

### 最佳实践

1. **日常使用**：保持窗口在后台，需要时查看
2. **AI 开发**：配合 AI 应用使用，实时监控资源
3. **性能调试**：观察高负载情况，优化应用

## 🔧 高级用法

### 自定义监控间隔

编辑 `SystemMonitor.swift` 中的更新间隔：

```swift
try? await Task.sleep(nanoseconds: 1_000_000_000) // 1秒
```

### 添加新的 AI 应用

编辑 `AIAppMonitor.swift` 中的应用列表：

```swift
private let knownAIApps: [String: String] = [
    "com.ollama.ollama": "Ollama",
    // 添加你的应用
    "com.yourapp.bundleid": "Your App Name",
]
```

## ❓ 常见问题

### Q: 为什么无法打开？

A: 确保：
- macOS 版本 >= 13.0
- 已安装 Swift Playgrounds（推荐）
- 或系统已安装 Swift 5.9+

### Q: 为什么检测不到 AI 应用？

A: 检查：
- 应用是否正在运行
- 应用是否在支持列表中
- 尝试重启监控器

### Q: 如何关闭？

A: 
- 关闭窗口即可
- 或按 `⌘Q` 退出
