# AI Monitor - 快速使用指南

## 🎯 最简单的使用方法

### 步骤 1: 打开项目

在 Mac 上，双击这个文件夹：
```
AIMonitor-Playgrounds.swiftpm
```

### 步骤 2: 点击运行

如果打开了 Swift Playgrounds：
- 点击右上角的 ▶️ 按钮
- 或按 `⌘R`

如果系统提示选择应用：
- 选择"Swift Playgrounds"
- 如果没有，从 App Store 免费下载

### 步骤 3: 查看监控

看到界面后，你会立即看到：
- 🖥️ CPU 使用率
- 💾 内存使用情况
- 🌐 网络流量
- 🤖 运行中的 AI 应用

## 🎨 颜色含义

- 🟢 **绿色** - 正常（< 50%）
- 🟠 **橙色** - 中等（50-80%）
- 🔴 **红色** - 高负载（> 80%）

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `⌘R` | 运行应用 |
| `⌘W` | 关闭窗口 |
| `⌘Q` | 退出应用 |

## 🛑 关闭应用

- 关闭窗口即可
- 监控会自动停止

## 💡 小提示

1. **保持运行** - 可以最小化窗口，继续监控
2. **检测 AI 应用** - 打开 Ollama 或 ChatGPT，会自动检测
3. **性能影响** - 监控器本身占用极低（< 1% CPU）

## ❓ 遇到问题？

### 无法打开

1. 确认 macOS 版本 ≥ 13.0
2. 安装 Swift Playgrounds
3. 尝试右键 → 打开

### 没有数据

1. 点击运行按钮
2. 等待 1-2 秒数据刷新
3. 检查系统权限设置

### 检测不到应用

1. 确认应用正在运行
2. 应用需要在支持列表中
3. 5 秒后自动刷新
